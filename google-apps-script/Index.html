ERP Properti & Konstruksi — konfigurasi belum lengkap

Backend belum menampilkan aplikasi karena alamat frontend React belum ditetapkan. Ini kondisi tertutup secara default, bukan data contoh.

  1. Deploy frontend React ke URL HTTPS yang tetap.
  2. Di Apps Script buka Project Settings → Script Properties.
  3. Isi ERP_FRONTEND_URL, SPREADSHEET_ID, dan GOOGLE_OAUTH_CLIENT_ID.
  4. Tambahkan email administrator pertama ke ADMIN_EMAILS, lalu deploy ulang web app.

Jangan bagikan spreadsheet database ke akun pengguna biasa. Seluruh akses data harus melewati autentikasi dan otorisasi backend.
