ERP Properti & Konstruksi

Backend Google Apps Script dan sumber data cloud belum dikonfigurasi lengkap.

Isi Script Properties ERP_FRONTEND_URL, GOOGLE_CLIENT_ID, dan ERP_ADMIN_EMAILS. Nilainya harus sesuai dengan domain frontend dan OAuth client Google.

Data lama pada browser tidak akan diunggah otomatis. Setelah login admin, pilih sendiri apakah akan memulai dengan data kosong atau menyalin data lokal.
